# Security Policy

## Reporting a Vulnerability

**Do not open a public issue.** Send details to **hippmem@gmail.com**.

You will receive a response within 48 hours with an assessment and
expected timeline for a fix.

## Supported versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Scope

This policy covers the hippmem-py Python package. Security issues in the
underlying Rust engine (hippmem-engine) are handled by the main HIPPMEM
project at https://github.com/hippmem/hippmem.
